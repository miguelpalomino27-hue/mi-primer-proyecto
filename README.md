## 📌 Descripción del laboratorio

### 🎯 Objetivo
Configurar el entorno de trabajo utilizando Git, GitHub y Visual Studio Code, así como crear un repositorio remoto para el control de versiones del proyecto.

### 🛠️ Herramientas utilizadas
- Visual Studio Code
- Git
- GitHub
- Node.js

---

## ⚙️ Pasos realizados

1. Se creó una carpeta para el proyecto.
2. Se abrió la carpeta en Visual Studio Code.
3. Se inicializó el repositorio con `git init`.
4. Se creó el archivo `index.js`.
5. Se agregaron los archivos al área de preparación con `git add .`.
6. Se realizó el primer commit.
7. Se creó un repositorio en GitHub.
8. Se conectó el repositorio local con el remoto.
9. Se subió el proyecto a GitHub con `git push`.
